Get the app

Same exams, logins, and teacher tools as the website — laid out for a phone screen. No Play Store or App Store needed.

You’re already in the installed app. Use Log in from Home.

Android

  1. Tap Install app below.
  2. Confirm. A Dipsan Academy icon appears on your home screen.
  3. Leave the browser and open that icon (full screen, no address bar).

If the button does nothing, open Chrome menu ⋮ → Install app / Add to Home screen.

iPhone

Apple does not allow installing unsigned apps from a link. Use Safari (not Chrome) to add the real full-screen app:

  1. Tap the Share button.
  2. Choose Add to Home Screen → Add.
  3. Leave Safari. Open the new Dipsan Academy icon.
